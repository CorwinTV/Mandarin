# Security Policy

## Supported Versions

This project is under active development. Only the latest version on the `main` branch is supported.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you find a security issue, please open a GitHub Issue or contact the maintainer.

Do not publicly share exploit details until the issue has been addressed.
